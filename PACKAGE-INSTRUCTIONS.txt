澜琅 1.6.59 免安装版

1. 将整个 LangLang 文件夹解压到任意可写目录。
2. 双击 LangLang.exe 启动，不需要安装 Python。
3. 店铺、密钥、登录态、订单、商品、上货任务和经营数据固定保存在：
   %LOCALAPPDATA%\LangLang\data
   该目录与程序解压目录完全分离。升级、重新解压、覆盖旧版、移动程序目录或
   重启电脑都不会清空这些数据。分享包本身不包含这个目录。
4. 软件启动时检查备份，并每 4 小时自动备份数据库到数据目录下的 backups 文件夹，
   保留最近 30 份。新版本首次启动会补一份当前完整数据。
5. 从旧版升级时，若旧解压目录中存在 data\weimi_manager.db，新版首次启动会自动复制
   数据库、扫码登录缓存和网页会话；旧目录中的文件不会被删除。
6. AppSecret 和登录 Cookie 使用当前 Windows 用户的 DPAPI 加密。同一台电脑、同一个
   Windows 用户重装或升级后可继续使用；换电脑或换 Windows 用户后必须重新填写密钥和扫码登录。
7. 可在“账号”页面查看固定数据目录、最近自动备份，并手动备份或恢复数据库。
8. 本版本起支持 GitHub Releases 自动更新。软件每次启动自动检查，运行期间每 30 分钟
   再检查一次；“更多 → 检查更新”也可手动检查。
9. 普通更新提供“关闭弹窗”；重大故障版本为强制更新，只有“立即更新”，未完成更新前
   不能继续使用。
10. 更新包使用 HTTPS 下载并进行 SHA256 校验。GitHub 网页下载地址不可访问时，
    客户端会自动改用 GitHub API 获取清单和更新文件，不需要局域网共享或本机固定目录。
11. 1.6.21 及以前版本不包含自动更新器，需要手动安装一次 1.6.22。以后的新版本
    可直接点击更新弹窗自动安装并重启。
12. 本版本新增云岚登录。首次启动需使用账户名和密码登录，并按页面提示完成
    邮箱验证和卡密授权。
13. 每个登录账户使用独立的数据目录。首次登录的账户会复制旧版 data 目录中的
    店铺和登录资料，旧数据不会被删除。
14. 登录令牌使用当前 Windows 用户的 DPAPI 加密保存。升级和重新解压不会丢失，
    但换 Windows 用户或换电脑后需要重新登录。
15. 授权时间以 Supabase 服务器时间为准；最近一次成功联网验证后，最多允许
    1 小时离线宽限。
16. 账号登录固定使用微信官方多账号扫码入口；选择页支持 iframe 和可点击文本控件，
    自动全选、登录并逐个保存所有可见子账号登录态。
17. 更新器支持网络瞬时失败重试、更新包预复制与版本校验；新版启动失败时自动恢复
    原程序目录。
18. 更新确认后才启动安装器，避免 90 秒等待在用户确认前提前开始。
19. 安装器会等待同一目录的全部 LangLang.exe 进程，并禁止同一目录重复启动多个实例。
20. 1.6.28 起更新下载默认使用 Windows 系统代理；可设置
    LANGLANG_UPDATE_DIRECT=1 强制直连。
21. 1.6.43 起标题栏提供“任务日志”：联网功能、自动轮询、类目提交核验
    和自动更新都会记录状态、耗时、店铺、结果与失败原因。
22. 1.6.44 起批量上货会直接读取店铺默认运费模板和默认售后地址；
    即使店铺没有在售商品也能正确补齐发货配置。主图不足三张的商品会在本地
    提前拦截，不再提交到微信并消耗额度。
23. 1.6.45 起数据包主图不足三张时，优先使用商品 SKU 图补足，其次使用
    同商品详情图补足到三张；不会重复使用同一张图片。
24. 1.6.46 起上货模板可选择“出售中 / 仓库 / 草稿箱”，默认出售中；
    上货任务支持多商品、多店铺并发执行。商品管理改为后台查询和分页渲染，
    避免大数据量时点击页面卡顿。任务页可把此前已上传的草稿商品提交上架。
25. 1.6.47 起微信数据包会自动修正类目对象格式，并按官方类目规则补齐
    主要材质、面料材质和成分含量等必填参数。重复商品过滤默认只拦截本店铺，
    可切换为本电脑全部店铺或关闭过滤。
26. 1.6.48 起已上货来源商品会保存到独立上传历史；清空上传任务后过滤仍有效。
27. 1.6.49 修复店铺管理右键打开后台可能打开其他已勾选店铺的问题；
    类目“成分含量”按官方数值加单位格式生成，例如 `100 %`。
28. 必填商品属性改为由官方类目规则驱动，不局限于服装材质；会选择类目
    允许值，并从标题提取尺寸、容量、重量等数值。通用文本、布尔、日期
    和数值字段也有兜底，模板中的 `属性名=值` 仍可手动覆盖。
29. 1.6.50 起关闭应用不再同步等待云端店铺保险箱推送，窗口会立即关闭；
    云端同步继续由后台变更同步和定时同步完成。
30. 1.6.51 起上货成功立即更新本地提审额度和商品总数；上传任务完成后
    自动刷新受影响店铺。店铺管理手动刷新改为最多 6 家并行，并逐店显示结果。
31. 1.6.53 店铺分组改为独立持久化数据：空分组也会保留，可新建、重命名、
    删除，并将一家或多家店铺批量设置到分组。上货弹窗支持一次选择多个分组，
    自动勾选组内全部店铺。
32. 1.6.53 上货遇到“目标类目未开通/无权限”时，会自动提交该商品所需类目的
    开通申请；类目立即生效会自动重试上货。审核中的商品标记为“待类目生效”，
    软件运行期间每 10 分钟自动检查并在生效后恢复上货。
33. 1.6.54 登录时勾选“保存密码”后，账户名和密码会使用 Windows DPAPI
    加密保存；下次启动自动预填账户与密文密码，只需点击登录。
34. 1.6.54 授权有效且尚未到期的账户直接进入工作台，不再显示卡密页面。
    只有授权真正到期后才显示续费卡密页面，并且只保留卡密验证操作。
35. 1.6.54 店铺页面遇到数据库已存在但列表异常为空的运行状态时，会自动从
    当前账户的磁盘数据库重新加载，避免 qweasd 等账户错误显示 0 家店铺。
36. 新增正式测试账号：账户名 `zpfly`，密码 `z12345678`，拥有永久测试授权。
37. 1.6.55 店铺页面在数据库对象异常返回空列表时，会使用独立只读 SQLite
    连接直接读取当前账户数据库，并记录恢复事件，避免已有店铺被错误显示为 0。
38. 1.6.56 主界面启动后强制检查店铺页是否为空；如果尚未渲染，会自动刷新，
    最多连续重试 5 次，并记录每次店铺读取结果。
39. 1.6.57 启动补刷新不再因为旧表格残留行而提前退出，会先强制重绘店铺页，
    再根据实际行数决定是否继续重试。
40. 1.6.58 在主窗口构造完成、进入事件循环前再次打开店铺页并同步执行刷新，
    同时在刷新函数入口记录日志，确保启动刷新不会被窗口初始化流程跳过。
41. 1.6.59 启动时强制校验主窗口持有的店铺页类型，发现旧页面对象时替换为
    当前正式店铺页，并记录实际页面类名、刷新行数和账户数据库路径。
42. 当前测试构建内置 Chromium 浏览器，采购账号授权、1688 登录和微信店铺登录
    不再依赖电脑是否安装 Chrome、Edge 或其他浏览器。每个账号继续使用独立
    浏览器配置和登录缓存。
